# CelebStockz store economy rules

- STKZ is closed-loop in-game currency with no cash redemption or withdrawal.
- Celebrity packs are deterministic permanent unlocks, not random loot boxes.
- Real-money deposits do not count as trading profit for competitive ranking logic.
- The free reset returns the game balance to 10,000 STKZ plus any unspent purchased STKZ.
- Permanent celebrity-pack entitlements survive resets.
- Ordinary/game STKZ is consumed before purchased STKZ.
- Selling shares creates ordinary/game STKZ, not purchased STKZ.
- Stripe webhook fulfilment is the only path that grants paid entitlements on web.
